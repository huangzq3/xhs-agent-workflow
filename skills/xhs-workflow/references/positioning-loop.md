# 定位生长闭环

账号定位不是一次填写完成的身份答案，也不能交给平台流量被动决定。工作流将其视为一个有边界的搜索过程：创作者选择稳定底座与红线，运行助手设计可证伪假设，内容承担验证任务，复盘综合多路证据，内容负责人只在证据链闭合后接受阶段性收敛。

## 四个层级

1. 创作者方向：价值观、真实能力、关系姿态、商业去向、内容与信任引擎、红线。
2. IP 核心：长期承诺、可信理由、希望形成的关系和记忆；由创作者选择与受众反馈共同塑造。
3. 平台账号定位：IP 核心在小红书特定人群、分发环境和内容形式中的阶段性表达。
4. 内容探针：单个选题或稿件对某些定位假设的探索、确认或主动挑战。

单篇内容不得直接改写上层。创作者方向变化进入账号战略 revision；账号定位变化进入 persona revision；标题、结构和发布方式变化进入内容或分发实验。

## 定位状态

`persona.mode` 为兼容摘要：`assumed` 表示仍在搜索，`validated` 只表示当前声明范围内暂时稳定，不代表永久市场真相。真实成熟度由下列字段表达：

- `positioning_state.phase`：`exploration`、`consolidation`、`stable_within_scope` 或 `reopening`；
- `positioning_state.scope`：结论适用的平台、受众、内容与时间范围；
- `stable_core`：内容负责人主动选择、暂不随短期数据改变的部分；
- `open_questions`：尚未获得答案的问题；
- `anti_audience` 与 `anti_positioning`：不主动吸引的人群和不希望形成的账号认知；
- `review_by`：阶段性结论的复核时间。

每条定位假设独立记录组成部分、可观察推论、反驳信号、成熟度、把握度、适用范围、正反证据和复核时间。不得用整份 Persona 的单一状态掩盖各项假设成熟度不同。

## 可追溯链

```text
persona hypothesis
  ↓ persona revision + hypothesis_refs + pillar_id
topic candidate positioning_trace
  ↓ G2 确认后不得静默改变
content positioning_trace
  ↓ G3 校验与选题完全一致
metrics_snapshot + review hypothesis_results
  ↓ 每个绑定假设必须得到 supported / refuted / inconclusive / not_tested
experiment 或 persona 新 revision
```

`positioning_trace` 同时记录受众分组、受众任务、交付价值、证据职责、记忆资产和探针角色。若创作时改变任何一项，先修订选题并重新确认，不能只改稿件字段。

## 修订谱系

定位的“长出来”必须能回放，不能只看到修改后的结果。Schema 2.4.0 的非首版 persona 在 G1 前必须：

1. 用连续递增的 `revision` 和 `supersedes_artifact_id` 回指已确认上一版；
2. 继续使用上一版战略，或使用它的后续已确认战略；
3. 同一战略下修订时，至少引用一份真实、可回指上一版 persona 的复盘；
4. 如果声明承接定位实验，该实验必须有当前有效 G6，其关联复盘也必须在本次修订证据中。

因创作者方向或账号战略变化而修订定位时，证据来自已确认的战略版本谱系，不强行伪造平台复盘。这区分了“创作者主动选择发生变化”与“市场证据促使定位生长”。

## 五路证据

复盘必须显式记录全部证据流，即使状态是缺失或不适用：

| 证据流 | 回答的问题 |
|---|---|
| 受众共鸣 | 目标受众是否出现，是否获得价值，是否用预期语言描述账号 |
| 内容兑现 | 稿件是否真正履行受众任务、交付价值和证据职责 |
| 平台分发 | 内容是否获得足以判断的合格曝光，分发偏差是否仍是替代解释 |
| 创作者适配 | 真实经验、持续意愿、生产成本和心理/声誉成本是否可持续 |
| 业务适配 | 吸引的人和需求是否符合长期用途；不适用时必须明确记录 |

平台指标不能独立证明定位成立。受众使用的语言、关注理由、合格需求、错误期待和无反应都记录为 `market_mirror`。内容没有兑现承诺或有效曝光不足时，只能得出 `inconclusive` 或 `not_tested`，不得支持或推翻定位。

## 探索与优化

- `exploration_probe` 用于早期未知较多的阶段，围绕一个明确问题安排不同受众、价值、证据或形式组合，目标是提高信息增益；不伪装成严格单变量因果实验。
- `controlled_optimization` 用于定位相对稳定后的标题、开头、结构、视觉或分发优化，必须明确唯一调整项和保持不变部分。

两类实验都要预先定义有效曝光规则、内容兑现规则、证据流、观察窗口和停止条件。

## 阶段性稳定门禁

`mode=validated` 与 `phase=stable_within_scope` 只有同时满足以下条件才可通过 G1：

1. 建立新 revision，并明确引用已确认的上一版定位和当前已确认的账号战略；
2. 阶段性成立的假设能追溯到上一版的同一陈述；
3. 至少两篇不同且具有有效 G3 的内容共同支持，而不是单篇异常表现；
4. 引用的复盘与数据快照真实存在、状态有效，并逐项支持对应假设；
5. 内容兑现和有效曝光均达到本轮预设规则；
6. 受众共鸣、内容兑现、平台分发和创作者适配均被实际评估，其中受众共鸣、内容兑现和创作者适配形成正向证据；
7. 至少存在一条受众市场镜像，且已经复核反向证据；
8. 明确结论适用范围、局限和下次复核时间。

稳定化仍是可撤销结论。新证据冲突、受众语言变化、创作者供给不可持续、平台环境变化或业务方向变化时，进入 `reopening`，而不是在旧版本上静默改写。
