# Topic report 质量检查

## 契约

- [ ] 输入 persona 已获 G1，账号与 run 一致。
- [ ] 正式输出为 topic_report JSON，Markdown/HTML 由 JSON 生成。
- [ ] 内容负责人原始选题被原样保留。
- [ ] 候选 ID、证据 ID 和选中 ID 可互相解析。

## 证据

- [ ] 每条平台或网页证据有 URL、采集时间和局限。
- [ ] 所有引号内容都可核对且 quote_verified=true。
- [ ] 证据不足的候选标为低置信度或 hypothesis。
- [ ] 没有示例数据、伪造评论或伪造指标。

## 判断

- [ ] 分数由证据导出，没有强制高、中、低分布。
- [ ] 观察、推断和建议相互区分。
- [ ] 每个候选列出风险或反证。
- [ ] 没有承诺点赞、浏览或爆款结果。

## HITL

- [ ] 审阅视图展示来源等级、局限和 payload hash。
- [ ] 内容负责人明确选择 topic ID。
- [ ] G2 记录人工身份、时间和决定。
