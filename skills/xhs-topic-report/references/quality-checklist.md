# 选题分析质量检查

## 契约

- [ ] 输入账号定位已经人工确认，账号与本轮任务一致。
- [ ] 内部机器记录通过校验，正式人工输出为由其生成的中文 HTML。
- [ ] 内容负责人原始选题被原样保留。
- [ ] 候选 ID、证据 ID 和选中 ID 可互相解析。

## 证据

- [ ] 每条平台或网页证据有 URL、采集时间和局限。
- [ ] 所有引号内容都可核对且 quote_verified=true。
- [ ] 证据不足的候选标为低置信度或 hypothesis。
- [ ] 没有示例数据、伪造评论或伪造指标。

## 判断

- [ ] 分数由证据导出，没有强制高、中、低分布。
- [ ] 观察、推断和建议相互区分。
- [ ] 每个候选列出风险或反证。
- [ ] 没有承诺点赞、浏览或爆款结果。

## 人工审阅

- [ ] HTML 展示来源等级、局限、风险和当前需要作出的决定。
- [ ] 页面不包含原始 JSON、内部字段名、阶段号或未经翻译的状态值。
- [ ] 内容负责人通过候选标题与核心角度明确选择选题，不需要填写内部编号。
- [ ] “选题确认”记录人工身份、时间和决定。
