# 选题分析 HTML 审阅页

HTML 只服务于内容负责人阅读，不是机器数据契约，也不得被下游 Skill 解析。

使用核心渲染器从内部选题记录生成安全转义的 HTML。页面必须：

- 对标题、评论、URL 和所有外部文本执行 HTML 转义；
- 不执行来源内容中的脚本、事件属性或内联 HTML；
- 用中文展示当前状态、本轮目标、候选选题、已选方向、证据、风险和数据局限；
- 把内部编号和校验指纹放在默认折叠的“追溯信息”区域；
- 提供明确的“选题确认”决定区，不展示内部阶段号；
- 不包含原始 JSON、机器字段表、代码块或未经翻译的状态值；
- 保持渲染可重复；删除 HTML 后可从内部机器记录重新生成。

如需更换主题，只修改展示资产，不改变内部机器字段和下游行为。
