# 严重度与审计维度

本规则只定义通用问题类型，不包含任何账号或品牌的具体文风约定。

## P0，阻断定稿

- 可证实的事实错误，或与可靠来源直接冲突。
- 关键数字、时间、身份、因果结论没有可核对来源。
- 引语被改词、无归属，或把转述伪装成原话。
- 时间线、人物身份、否定范围或前后命题出现实质矛盾。
- 跨表面差异导致最终发布内容表达不同事实，例如标题与正文结论相反。
- 材料或证据无法支持会实质影响读者判断的核心主张。

P0 必须附带原文位置和判断证据。仅凭审计者偏好不能建立 P0。

## P1，需要修订或人工决定

- 论证跳步、关键限定条件缺失或存在两种实质不同的合理解释。
- 结构重复、双重结尾、视角混用、指代不清或段落归属错误。
- 标题、正文、卡片、口播或字幕没有交付同一核心价值。
- 非核心事实暂时无法核实，但保留会降低可信度。
- 显式规则包中的重要约束未满足，但尚未造成事实或语义错误。

P1 不能由审计 Agent 自行豁免。未修订时只能交内容负责人决定。

## P2，非阻断建议

- 错别字、病句、搭配不当、重复词和术语前后不一致。
- 局部节奏、信息密度或移动端可读性问题。
- 不改变事实、立场和理解方向的轻微格式问题。

## 核心审计维度

1. `fact_and_source`，事实与来源。
2. `quote_and_attribution`，引语与归属。
3. `logic_and_consistency`，逻辑、身份和时间线。
4. `structure_and_redundancy`，结构与重复。
5. `language_and_terminology`，语法、用词和术语。
6. `cross_surface_consistency`，所有最终呈现表面的一致性。
7. `uncertainty_and_decisions`，不确定信息与待人工决定事项。

## 分类边界

- 同义反复通常是 P1，不因为出现重复就自动升为 P0。
- 风格规则违规通常是 P1 或 P2；只有造成事实、语义或明确合规风险时才可能成为 P0。
- “有来源”不等于“已证实”。需要判断来源是否直接支持该主张、是否过期、是否只提供了搜索摘要。
- 审计状态不是质量分。不得设定“达到 90 分即可通过”一类通用阈值。
