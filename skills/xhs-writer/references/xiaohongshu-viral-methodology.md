# 内容质量方法

本方法用于提高内容清晰度和可测试性，不预测“爆款”。

## 五个检查面

1. 受众任务：内容解决的具体问题是否清楚。
2. 证据：重要主张是否可核对，限定条件是否保留。
3. 结构：标题、开头、主体和结尾是否交付同一价值。
4. 表达：移动端是否易读，是否避免空泛和过度营销。
5. 可测试性：下一轮能否只改变一个主要变量并观察结果。

## 创作顺序

1. 先写一句价值承诺和适用对象。
2. 列出必须保留的事实、不能声称的内容和素材限制。
3. 选择图文、视频或文本结构。
4. 生成两个差异明确但事实一致的候选。
5. 由内容负责人选择方向。
6. 记录 change_summary 和待验证假设。

不得用单一案例、点赞截图或无来源经验总结为跨赛道规律。
