# 中文表达自然化

自然化只改变表达，不改变事实。

## 可以做

- 删去重复、空泛和机械的过渡句。
- 把抽象名词改成清晰动作。
- 调整句长、节奏和段落。
- 使用 persona 已批准的语气特征。
- 把内容负责人已提供的具体场景写得更清楚。

## 不可以做

- 新增“亲测”“用了几天”“身边朋友都在用”等经历。
- 新增数字、效果、排名、评价或客户案例。
- 把假设改写成事实。
- 把转述改成原文引语。
- 为了显得真实而虚构口头禅、失误、时间、地点或情绪。
- 改变医疗、金融、法律等高风险内容的限定条件。

## 执行方法

1. 标记原文中的事实、观点、假设和个人经历。
2. 只在同一类别内改写。
3. 对无法确认的第一人称陈述改为中性表达，并列入待确认项。
4. 把所有新增事实要求退回内容负责人确认。
5. 在 content artifact 的 change_summary 中记录实质变化。

自然感来自具体、克制和一致，不来自伪造经历。
