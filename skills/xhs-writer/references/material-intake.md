# 素材接入

## 接入步骤

1. 接收明确文件或目录路径。
2. 递归扫描允许的图片、视频和文档扩展名；忽略隐藏文件、缓存和未知二进制。
3. 为每个文件计算 SHA-256、媒体类型、尺寸或时长。
4. 请账号负责人声明 rights_basis；不能确认时设为 pending。
5. 标记是否包含人脸、聊天记录、账号后台、联系方式或其他个人数据。
6. 交给可能在工作区外处理数据的原生能力前，单独确认 `external_processing_approved`。
7. 只把 verified 素材写入 content artifact。

## 选择策略

- 原始截图和实拍素材优先于装饰性生成图，但仍需隐私和权利确认。
- 图文比例由内容目标决定；推荐 3:4 或平台当前支持的竖版比例，不把 9:16 写成唯一真理。
- 没有可用素材时可以生成纯文本卡片，前提是本地渲染器真实可用。
- 原生生图能力不可用时输出 `image_job`、文案和布局规格，不声称图片已经生成。

## 失败处理

- 目录无法递归读取：停止并报告具体路径。
- 文件损坏或无法识别：登记错误，不把尺寸写成 0×0 后继续。
- 权利或外部处理许可缺失：保留待处理，不进入发布资产列表。
