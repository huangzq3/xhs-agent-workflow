# 素材接入

## 接入步骤

1. 接收明确文件或目录路径。
2. 递归扫描允许的图片、视频和文档扩展名；忽略隐藏文件、缓存和未知二进制。
3. 为每个文件计算 SHA-256、媒体类型和字节数；视频在 `ffprobe` 可用时额外登记时长与流信息。
4. 图片先标记为 `pending_agent_review`，由当前 Agent 实际查看内容、文字、构图和敏感信息；文件清单脚本不解码图片像素。
5. 请账号负责人声明 rights_basis；不能确认时设为 pending。
6. 标记是否包含人脸、聊天记录、账号后台、联系方式或其他个人数据。
7. 交给可能在工作区外处理数据的原生能力前，单独确认 `external_processing_approved`。
8. 只把 verified 素材写入 content artifact。

## 选择策略

- 原始截图和实拍素材优先于装饰性生成图，但仍需隐私和权利确认。
- 图文比例由内容目标决定；推荐 3:4 或平台当前支持的竖版比例，不把 9:16 写成唯一真理。
- 没有可用素材时，只能调用已核对的 AI Agent 原生生图能力，或建立人工素材任务。
- 原生生图能力不可用时输出未执行的 `image_job`、文案和布局规格，不声称图片已经生成，也不调用本地栅格后备实现。

## 失败处理

- 目录无法递归读取：停止并报告具体路径。
- 文件为空、签名无法识别或 Agent 视觉检查失败：登记错误，不把该文件作为已核对素材继续。
- 权利或外部处理许可缺失：保留待处理，不进入发布资产列表。
