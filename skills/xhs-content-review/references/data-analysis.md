# 数据分析规则

## 指标分层

- stock_metrics：采集时点的累计值，例如当前浏览、点赞、收藏、评论、分享、粉丝数。
- flow_metrics：观察窗口内新增值，例如 24 小时新增浏览或涨粉。
- derived_metrics：由明确公式计算的比例；分母为零时写 null。
- trust_metrics：账号战略明确的信任形成指标，例如主页访问率、关注转化或有定义的深度互动；不得把任意互动率自动等同于信任。
- qualitative_metrics：依据明确 rubric 和证据，由人工评估的评论质量、需求匹配等非数值判断。

不得跨日期累加 stock_metrics。趋势使用相邻快照差值或平台提供的期间增量。

## 按内容形式

| 形式 | 常见可用指标 | 不适用时 |
|---|---|---|
| image | 曝光、阅读/点击、滑页深度、收藏、评论、分享 | 不计算视频完播 |
| video | 曝光、播放、平均观看、完播、留存、互动 | 无留存字段时写缺失 |
| text | 曝光、阅读、停留、互动 | 取决于平台是否提供 |

平台字段变化时保存原始字段名和采集时间，不猜测字段含义。

## 基线

优先级：

1. 同账号、同形式、相近发布生命周期的历史分位数。
2. 同一内容的前一快照。
3. 有来源的同赛道参考区间。
4. 无基线：只描述绝对值，不评级。

固定 5%、10% 等阈值不能作为默认跨账号诊断标准。

## 长尾

- initial 与 long_tail 快照分开标记。
- long_tail 必须记录 `checkpoint_days` 和前一快照引用。
- 检查点来自账号战略，不内置固定天数。
- 长尾贡献用相邻快照增量、搜索来源变化和信任变化描述，不把累计存量重复相加。

## 解释

每条诊断包含 observation、hypothesis、alternative_explanations、confidence 和 evidence_refs。一次快照通常只能支持相关性观察，不能证明原因。
