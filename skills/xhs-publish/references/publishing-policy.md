# 发布与发布后策略

账号运营策略中的内部发布规则是发布节奏与发布后动作的唯一配置来源。运行 Agent 不内置“发布后一天不能改”“同主题隔两天”等数字。

## 发布前检查

使用 `portfolio_cli.py check-policy --action publish` 生成 `policy_check`：

- “符合当前规则”：未发现违反当前策略的条件；仍需发布前确认；
- “需要人工判断”：阈值未配置、同主题仍在间隔期，或某项状态需要证据判断；发布前确认必须明确处理例外；
- “当前规则不允许”：策略明确禁止该动作，不得继续发布。

内部检查结果绑定账号策略版本和检查时间。账号运营策略修订后必须重新检查。内部仍可使用 `allowed`、`needs_human` 与 `blocked`，但不得原样出现在人工提问或 HTML 中。

## 发布后修改与删除

远端修改和删除不属于自动恢复动作：

1. 先用 `check-policy --action modify|delete` 查看当前策略；
2. 需要人工确认时，对人工显示“需要人工判断”；
3. 账号负责人用 `record-post-publish` 明确批准或拒绝，并写明理由；
4. 账号规则禁止时不得记录为确认通过；
5. 记录决定本身不等于已经在平台执行，实际外部动作仍要单独核验与审计。

发布结果无法确定时，对人工显示“发布结果待核对”，不得把删除或重发当作自动补偿。
