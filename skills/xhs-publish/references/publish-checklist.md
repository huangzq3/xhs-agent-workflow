# 发布前检查

## 账号与内部记录

- [ ] 账号、账号运营策略、内容库存与已定稿内容的内部引用明确且一致。
- [ ] 当前实际发布界面的账号与目标账号一致。
- [ ] 发布路径已确认使用已授权能力，或由账号负责人手动操作。
- [ ] 内部内容记录通过校验。
- [ ] 内容定稿确认仍对应当前版本。
- [ ] 库存状态为“可以发布”或“已排期”，且精确引用该内容。

## 内容

- [ ] 标题、正文、标签和素材顺序与预览一致。
- [ ] 事实、数字、引语和个人经历已核对。
- [ ] 没有未解决的高风险主张或隐私信息。
- [ ] 内容负责人已查看相对上一版的修改内容。

## 素材

- [ ] 每个文件存在且校验指纹一致。
- [ ] 所有素材权利均已核对。
- [ ] 没有通过移除、裁剪或遮挡水印规避授权。
- [ ] 人脸、聊天记录、后台截图等已获公开许可。

## 发布意图

- [ ] 可见范围、发布时间和目标账号明确。
- [ ] 定时发布已明确时区、最晚允许执行时间和可用的执行方式；能力未知时没有假定自动执行。
- [ ] 内容库存的计划时间与发布记录的定时时间一致。
- [ ] 发布预览的内部校验指纹已生成。
- [ ] 已按当前账号运营策略完成规则检查；不允许的动作已停止，需要人工判断的原因已用中文展示。
- [ ] 发布前确认由账号负责人明确作出。
- [ ] 本次发布前确认尚未被用于发布尝试。

## 定时执行

- [ ] 平台原生定时发布已保存可核对的排期凭据，且没有把“已排期”标成“已上线”。
- [ ] 运行工具到点唤醒或人工到点交接已在到点后重新核对账号、内容版本和发布规则。
- [ ] 当前仍在允许执行时间内；错过最晚时间时已经停止自动补发。

## 结果

- [ ] 只有获得平台内容记录或可验证链接才标记“已发布”。
- [ ] 已记录平台确认的实际上线时间和核对依据；没有使用计划时间、排期提交时间或执行开始时间代替。
- [ ] 平台明确拒绝且未创建内容时标记“发布失败”。
- [ ] 无法判断是否发布时标记“发布结果待核对”并停止重试。
- [ ] 发布成功后推进库存并按账号配置创建长尾检查点。
- [ ] 修改或删除远端内容时另行记录账号负责人的决定。
