# 试运营定位

试运营阶段的账号定位是可证伪假设，不是已经被市场验证的账号真相。

## 试运营定位（待验证）

- 至少写一个 `hypotheses` 条目；
- 每个假设说明陈述、状态和证据引用；初始状态通常为 `pending`；
- `validation_plan` 明确样本目标、要覆盖的差异维度、成功信号和停止条件；
- “账号定位确认”同意的是身份事实、表达边界、假设是否值得测试以及验证计划是否可接受，不是确认“定位已经正确”。

早期内容应覆盖不同内容目标、题材或形式，以提高信息增益。不得只复制同一种爆款表达来“验证”画像。

## 转为已验证定位

复盘必须逐项记录假设结果和证据。只有账号负责人接受证据并创建账号定位新版本后，才可改为已验证定位。样本不足、证据冲突或只有单篇异常表现时保持“试运营定位（待验证）”，或标记为“证据不足，暂不能判断”。

内部机器值仍使用 `mode=assumed` 与 `mode=validated`，但不得原样出现在人工提问或 HTML 标题中。
